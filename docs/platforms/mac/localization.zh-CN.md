# macOS 菜单栏中文本地化

## 概述
OpenClaw macOS 应用现在支持中文（简体）本地化。所有菜单项、状态消息和设置选项都已翻译成中文。

## 如何启用中文界面

### 方法一：系统级别设置
1. 打开"系统设置"（System Settings）
2. 点击"通用"（General）→"语言与地区"（Language & Region）
3. 将"简体中文"添加到首选语言列表
4. 重启 OpenClaw 应用

### 方法二：仅针对 OpenClaw 设置
1. 右键点击 OpenClaw 应用程序
2. 选择"显示简介"（Get Info）
3. 在"语言"部分选择"简体中文"
4. 重启 OpenClaw 应用

## 技术细节

本地化实现使用 SwiftUI 的内置本地化系统：
- 所有字符串都存储在 `.strings` 文件中
- 应用程序根据系统语言自动选择正确的翻译
- 如果翻译缺失，会自动回退到英语
