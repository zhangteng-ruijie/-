## Translation Philosophy

The Chinese translations follow these principles:

1. **Clarity**: Use clear, concise terminology that Chinese-speaking users can easily understand
2. **Consistency**: Maintain consistent terminology throughout the interface
3. **Natural**: Sound natural in Chinese while preserving the original meaning
4. **Professional**: Use professional terminology appropriate for a technical application
